טעינת שני הגיליונות

טענו את הקובץ holiday.xlsx ל־Power Query. בחלון הניווט סמנו את שני הגיליונות: Orders ו־Meta Data, כדי שה־Meta Data יהיה זמין לעיון לאורך כל התרגיל.

Power BI · English
Home → Get data → Excel workbook → holiday.xlsx
Navigator: Select multiple items → Orders + Meta Data → Transform Data
Excel · עברית
פתחו חוברת עבודה ריקה
נתונים ← קבל נתונים ← מקובץ ← מחוברת עבודה של Excel
בחלון "נווט": בחר פריטים מרובים ← Orders + Meta Data ← המר נתונים
חשוב: במהלך העבודה בצעו את פעולות הניקוי והשינויים על השאילתה Orders. השאילתה Meta Data מיועדת לעיון ולהשוואה בלבד.

Excel · עברית
המר ← תבנית ← חתוך

לאחר ביצוע Trim בדקו שוב.

Trim לעומת Clean: בתפריט תבנית אלה שתי פעולות שונות: חתוך (Trim) מסיר רווחים מיותרים מתחילת הטקסט ומסופו; נקה (Clean) מסיר תווי בקרה/תווים שאינם ניתנים להדפסה. במשימה זו השתמשו ב־חתוך.
